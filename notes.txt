This is a Hugo static site (https://gohugo.io/).

Several themes are kept in the repo while we decide which one to use:
- gruvbox  https://github.com/schnerring/hugo-theme-gruvbox  (Hugo module, vendored in _vendor/, needs `npm install`)
- archie   https://github.com/athul/archie                    (git submodule, themes/archie)
- papermod https://github.com/adityatelange/hugo-PaperMod     (git submodule, themes/PaperMod)

Shared config is hugo.toml; each theme has its own config-<theme>.toml.

First checkout:
- git submodule update --init --recursive
- npm install            (only needed for gruvbox)

To work:
- make serve THEME=gruvbox      (or archie / papermod)

To publish:
- make publish THEME=gruvbox    (= hugo build + ghp-import public + git push origin gh-pages)

Note: `hugo server` writes into public/ too, so always run the build right before publishing.

Blog:
- Posts live in content/blog/<slug>/index.md as page bundles (images next to the post).
- The Medium posts were imported with scripts/import_medium.py (see its docstring).
- The homepage lists the latest 10 posts; older ones are paginated.
